# Обмундирование: шляпы и ботинки (черновик v0.1)

Волшебники старые, им нужны только **шляпа** и **ботинки**.

- **Шляпа** — Мудрость, Удача, Сопротивление.
- **Ботинки** — Скорость, Защита, Здоровье.

## Редкость

| Редкость | Бонусы | Где выпадает |
|---|---|---|
| ⚪ Обычная | 1 характеристика | Лут обычных уровней |
| 🔵 Редкая | 2 характеристики | Лут, гарантированно после босса акта I |
| 🟣 Эпическая | 2 характеристики + свойство | Боссы актов II–III, редко в луте |
| 🟠 Легендарная | 3 характеристики + сильное свойство | Боссы актов III–IV |
| 🔴 Проклятая | Сильные бонусы + постоянный минус | Проклятые сундуки, особые события |

Шаг бонусов: Мудрость, Удача, Сопротивление, Защита — **+1**; Здоровье — **+2**;
Скорость — **+1**.

|---|---|---|---|

| Остроконечный колпак | ⚪ | +1 МДР | — |
| Колпак со звёздами | 🔵 | +1 МДР, +1 УД | — |
| Шапка-ушанка мага | 🔵 | +1 СП, +1 МДР | — |
| Шляпа с пеплом на полях | 🟣 | +1 МДР, +1 СП | Иммунитет к Горению |
| Колпак рассеянного | 🟣 | +2 УД | Раз за бой — посмотреть первую фишку до выбора цели |
| Тюрбан прорицателя | 🟣 | +1 МДР, +1 УД | Видит, какую способность босс использует следующей |
| Шляпа Старого Мерлина | 🟠 | +2 МДР, +1 УД, +1 СП | Раз за бой — Сосредоточенность |

## Комплекты

Шляпа и ботинки одного комплекта дают дополнительный бонус.

| Комплект | Шляпа + ботинки | Бонус комплекта |
|---|---|---|
| **Облачение Старого Мерлина** | Шляпа Старого Мерлина + Сапоги Семи Лиг | Хаос I в руках владельца всегда полезен |
| **Уют пенсионера** | Ночной колпак + Тапочки с помпонами | После каждого боя восстанавливает 2 ЗД |
| **Наряд книжника** | Корона книжного червя + Ботинки Отшельника | +1 слот книги |
| **Шутовской костюм** | Колпак дурака + Туфли танцующего скелета | Все Хаос-заклинания владельца бьют только врагов |
