# Клятвенный кодекс

*Свод обетов с пометками «уже не актуально» напротив половины пунктов.*

- **Класс:** Паладин в отставке
- **Мешочек:** ✨ Святость ×10 · 🔥 Огонь ×5 · 🌿 Земля ×4 · ⚫ Хаос ×1 (5 % / 6.9 % / 8.8 % на 1-е / 2-е / 3-е вытягивание)

Урон призванных существ, ядов и болезней в среднее не входит.
