# Книга Друида

*Между страниц растёт мох. Из корешка торчит жёлудь, который никто не решается вынуть.*

- **Редкость:** 🔵 Редкая
- **Класс:** Друид
- **Мешочек:** 🌿 Земля ×10 · 💧 Вода ×5 · ✨ Святость ×4 · ⚫ Хаос ×1 (5 % / 6.9 % / 8.8 % на 1-е / 2-е / 3-е вытягивание)

- **Особое:** Призванные звери встают на сторону кастующего. Характеристики зверей — в balance.md.
