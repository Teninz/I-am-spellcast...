*Учебник фехтования для магов. На полях — схемы ударов тростью.*

- **Класс:** Магус с тростью
- **Мешочек:** ⚡ Молния ×10 · 🔥 Огонь ×5 · 💧 Вода ×4 · ⚫ Хаос ×1 (5 % / 6.9 % / 8.8 % на 1-е / 2-е / 3-е вытягивание)

- **Особое:** Способность Магуса «Удар тростью» добавляет 1 урон после каждого каста по врагу — в таблицу не входит.
