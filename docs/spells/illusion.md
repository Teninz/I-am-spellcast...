# Книга Миражей

*Если смотреть на эту книгу долго, она притворяется другой книгой.*

- **Редкость:** 🔵 Редкая
- **Класс:** Иллюзионист
- **Мешочек:** 🌀 Иллюзия ×10 · 💧 Вода ×5 · 🔥 Огонь ×4 · ⚫ Хаос ×1 (5 % / 6.9 % / 8.8 % на 1-е / 2-е / 3-е вытягивание)
- **Распределение заклинаний:** Контроль 12 · Польза 10 · Урон 8
- **Особое:** Иллюзорный урон и лечение частично «возвращаются» через 2 хода — это указано в эффекте.
