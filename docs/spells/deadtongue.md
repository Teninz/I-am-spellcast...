# Книга Мёртвого Языка

*Написана на языке, на котором никто не говорит уже тысячу лет. Потому что все, кто говорил, умерли.*

- **Редкость:** 🔴 Проклятая
- **Класс:** без класса — только из лута
- **Мешочек:** 🌑 Тьма ×10 · 🔮 Тайна ×5 · 🔥 Огонь ×4 · ⚫ Хаос ×1 (5 % / 6.9 % / 8.8 % на 1-е / 2-е / 3-е вытягивание)
- **Распределение заклинаний:** Урон 20 · Проклятие 10
- **Особое:** ПРОКЛЯТАЯ. Каждый каст стоит кастующему 1 ЗД. Книгу нельзя выбросить или передать — только снять Святой водой или Свитком очищения (книга исчезает).
